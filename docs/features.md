# Карта функций

Что входит в первую версию каждой части, что позже и чего не делаем совсем.
Правило отбора: функция попадает в первую версию, только если без неё бот не продаёт или админ не может работать каждый день.

## Уведомления админам (часть `add-bot`)

Группа-форум, темы по видам событий, не по абонентам: абонентов могут быть десятки тысяч.

| Тема | Что приходит | Кнопки |
|---|---|---|
| Платежи | оплата, возврат, расхождение суммы | Бан, +7 дней, Открыть в админке |
| Пробные | взят пробный период | Бан, Открыть в админке |
| Новые | новый абонент | Бан, Открыть в админке |
| Поддержка | сообщения абонентов | ответ реплаем |
| Ошибки | панель не догоняет, касса молчит | |
| Безопасность | входы, неверные пароли, смена ключей | дублируется владельцу в личку |
| Сводка | итог дня | |

Каждую тему админ включает и выключает сам. Безопасность выключить нельзя.

## Правила, которые выросли из чужих ошибок

- Каждый исход оплаты говорит с абонентом: «оплачено», «отклонено», «на проверке». Тишины нет.
- Покупка целиком проходит текстом. Mini App это удобство, а не единственный путь: при медленном Telegram текст доходит, а приложение может не открыться.
- Одна логика покупки в ядре, бот и кабинет её только зовут.
- Настройка живёт в одном месте. Правка в админке всегда применяется.
- Любое «Назад» и любая кнопка сбрасывают ожидание ввода, чтобы случайный текст не стал промокодом или суммой.
- Ссылки на приложения не отдаются сырой схемой `happ://`: только кнопка, которая открывает приложение.
- Кнопка, которая ведёт в тупик, не показывается. Недоступное объясняется текстом.
- Обновление бота и команды серверу из бота и админки не делаем: это ломает установки.
