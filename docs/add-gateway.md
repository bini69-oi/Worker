# Как добавить кассу

Касса это одна папка в `pay/` и один тест. Ядро, баланс и подписки не меняются.

## 1. Папка и настройки

Создайте `pay/<имя>/<имя>.go`. В `init()` зарегистрируйте настройки кассы:

```go
func init() {
	settings.AddGateway("mykassa", "Моя касса",
		settings.Def{Key: "mykassa.token", Kind: settings.KindString, Group: "pay.mykassa", Secret: true,
			Desc: "API-ключ кассы"},
	)
}
```

`AddGateway` сам добавит общие настройки: `mykassa.enabled`, `.title`, `.sort`, `.min`, `.max`.
Секретные настройки хранятся в базе зашифрованными и в админке видны только как последние 4 символа.

## 2. Четыре метода и проверка вебхука

Касса реализует `pay.Gateway`:

| Метод | Что делает |
|---|---|
| `Name()` | имя кассы, оно же адрес вебхука `POST /pay/<имя>` |
| `Configured()` | ключи заполнены; касса без ключей абоненту не видна |
| `Create(ctx, p)` | создать счёт в кассе, вернуть ссылку и сумму в валюте кассы |
| `Status(ctx, p)` | спросить кассу о платеже, если вебхук потерялся |
| `Verify(r)` | проверить подпись вебхука и разобрать его |

Правила:

- Суммы в копейках `int64`. Строку «300.00» переводите в 30000 без `float`.
- `Verify` без верной подписи возвращает ошибку. Если касса не подписывает вебхуки, переспросите статус платежа у её API и верьте только ответу API.
- Ключи читайте из настроек на каждом запросе, тогда правка в админке действует без перезапуска.
- Ключ никогда не попадает в текст ошибки и в журнал.

Зачислять деньги касса не должна. Это делает ядро: `Verify` возвращает событие, ядро зачисляет его ровно один раз.

## 3. Тест

Каждая касса проходит общий набор `pay/gatewaytest`:

```go
func TestSuite(t *testing.T) {
	api := httptest.NewServer(fakeAPI()) // фейковый API кассы
	defer api.Close()
	g := New(cfg, api.URL, nil)
	gatewaytest.Run(t, gatewaytest.Case{
		Gateway:      g,
		Unconfigured: New(emptyCfg, api.URL, nil),
		Amount:       30000,
		Paid:         func(p core.Payment, amount int64) *http.Request { /* подписанный вебхук */ },
		Forged:       func(p core.Payment, amount int64) *http.Request { /* чужая подпись */ },
	})
}
```

Набор проверяет:

- касса без ключей не видна;
- создание счёта;
- поддельная подпись получает 401, денег нет;
- вебхук дважды зачисляет один раз;
- неверная сумма не зачисляется.

Образец простейшей кассы лежит в `pay/gatewaytest/fake.go`.

## 4. Подключение

Добавьте кассу в список в `cmd/worker` рядом с остальными. Больше ничего менять не нужно.
