# Ручная проверка бота

Проходится на тестовом боте и тестовой панели перед архивом `add-bot`. Каждый пункт: сделать и увидеть результат.
Тесты проверяют логику, этот список проверяет настоящий Telegram на телефоне.

## Подготовка

- [ ] `.env` с токеном тестового бота, своим Telegram ID, тестовой панелью. `worker` запущен, в журнале «worker запущен» без ошибок.
- [ ] В админке (пока командами) есть тариф с ценой 30 дней, включены Stars и пробный период.
- [ ] Создана группа с темами, бот добавлен админом, `/bind <код>` прислан. В группе семь тем.

## Абонент

- [ ] `/start` с чистого аккаунта: меню, кнопка «Попробовать бесплатно».
- [ ] Пробный период: приходит «включён», потом экран подключения. В теме «Пробные» событие с кнопками.
- [ ] «Добавить в Happ» на iPhone и Android: приложение открывается и само добавляет подписку. VPN включается.
- [ ] «Скопировать ссылку» кладёт ссылку в буфер.
- [ ] Покупка без денег: экран с ценой, балансом и недостачей. «Пополнить на …» → Stars → оплата → подписка оформилась сама, пришло уведомление.
- [ ] Двойной быстрый клик «Оплатить с баланса»: списано один раз.
- [ ] Пополнение картой (тестовая касса): кнопка ведёт на оплату, после оплаты возврат в бота на статус платежа.
- [ ] Устройства: список совпадает с панелью, «❌» отвязывает.
- [ ] Перевыпуск ссылки: старая ссылка в приложении перестала работать, новая работает.
- [ ] Промокод кнопкой и ссылкой `?start=promo_КОД`.
- [ ] Реферальная ссылка: второй аккаунт по ней, у первого «Приглашено: 1».
- [ ] Удалить сообщение-экран и нажать кнопку в старом сообщении: бот присылает новый экран.

## Поддержка

- [ ] Текст абоненту без кнопки уходит в тему «Поддержка» с карточкой, абонент видит «Отправлено в поддержку».
- [ ] Ответ реплаем в теме приходит абоненту. Сообщение без реплая абоненту не уходит.
- [ ] Фото от абонента и от админа доходят.

## Админ

- [ ] Под оплатой в «Платежах» кнопки «Бан», «+7 дней», «Открыть в админке». «Бан» меняется на «Разбанить», абонент видит текст о блокировке.
- [ ] Чужой человек в группе жмёт «Бан»: «Нет прав».
- [ ] Вход в админку: в личке три кода, нажатие верного пускает, неверного отклоняет.
- [ ] Техработы: абонент видит текст о работах, владелец пользуется ботом.
- [ ] Абонент заблокировал бота: напоминание не падает в повторы, в журнале нет ошибок по кругу.

## Режим разработки

- [ ] `bot.polling = true`, перезапуск на своём компьютере без https: бот отвечает.
