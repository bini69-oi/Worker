# Proposal

## Why

Владелец уже продаёт VPN через другой бот или руками в панели. Чтобы переехать на Worker, абоненты должны появиться у нас
со своими сроками и ссылками, ничего не переподключая. Источник один для всех: панель Remnawave, где абоненты уже есть.

## What Changes

- Команда на сервере `worker import panel`: читает всех пользователей панели и заводит у нас абонентов и подписки.
- Сначала всегда пробный прогон: сколько будет заведено, сколько пропущено и почему. Запись только с флагом `--apply`.
- Срок, лимиты трафика и устройств, сквады и ссылка подписки сохраняются как в панели. Абонент ничего не переподключает.
- Абонент привязывается по Telegram ID из панели. Пользователи без Telegram ID пропускаются с отчётом.
- Повторный импорт не заводит дублей.
- Владелец получает итог в тему «Безопасность» и в журнал действий.
- Кнопка импорта в админке появится в `add-admin` и зовёт ту же функцию ядра.

**Не входит:** импорт балансов, рефералов и истории из баз других ботов, импорт по username.

## Capabilities

### New Capabilities
- `panel-import`: перенос абонентов из панели.

### Modified Capabilities

Нет.

## Impact

- `panel`: постраничный список пользователей.
- `core`: `ImportPanel`, снимок лимитов подписки.
- `cmd/worker`: команда `import panel`.
- Хранилище: миграция `006_import.sql`.
