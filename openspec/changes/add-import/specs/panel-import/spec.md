# Spec Delta

## Purpose

Перенос абонентов из панели Remnawave в Worker без переподключения: сроки, лимиты и ссылки остаются прежними.

## ADDED Requirements

### Requirement: Пробный прогон по умолчанию
Импорт SHALL без флага `--apply` ничего не записывать и показывать отчёт: сколько будет заведено, сколько пропущено и почему.

#### Scenario: Посмотреть до переноса
- **WHEN** владелец запустил `worker import panel`
- **THEN** в базе ничего не изменилось, в отчёте числа и причины пропусков

### Requirement: Срок, лимиты и ссылка сохраняются
Перенесённая подписка SHALL иметь срок, лимиты трафика и устройств, сквады и ссылку как у пользователя в панели, и сверка не меняет их.

#### Scenario: Пользователь с 50 ГБ до 15.03
- **WHEN** импортирован пользователь панели с лимитом 50 ГБ и сроком до 15.03
- **THEN** у абонента подписка до 15.03, после сверки в панели по-прежнему 50 ГБ и та же ссылка

### Requirement: Привязка по Telegram ID
Пользователь панели SHALL привязываться к абоненту по Telegram ID. Без Telegram ID он пропускается.

#### Scenario: Без Telegram ID
- **WHEN** у пользователя панели нет Telegram ID
- **THEN** он пропущен с причиной «нет Telegram ID»

### Requirement: Повтор без дублей
Повторный импорт SHALL пропускать пользователей, подписка которых уже есть у нас.

#### Scenario: Импорт дважды
- **WHEN** владелец запустил импорт с `--apply` второй раз
- **THEN** новых подписок нет, все пропущены с причиной «уже перенесён»

### Requirement: Только владелец
Импорт SHALL запускать только владелец: командой на сервере или кнопкой в админке после «Да» в Telegram. Итог пишется в журнал действий.

#### Scenario: Помощник нажал импорт
- **WHEN** помощник вызвал импорт из админки
- **THEN** отказ `ErrOwnerOnly`, в журнале запись, владелец получил тревогу

### Requirement: Продление переносом на наш тариф
Покупка тарифа при живой перенесённой подписке SHALL идти как смена тарифа со следующего периода.

#### Scenario: Купил месяц
- **WHEN** абонент с перенесённой подпиской до 15.03 купил «Месяц»
- **THEN** до 15.03 лимиты панели, с 15.03 «Месяц» на 30 дней
