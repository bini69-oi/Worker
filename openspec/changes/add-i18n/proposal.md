# Proposal

## Why

Абоненты пишут боту не только по-русски. Без английского часть людей уходит на первом экране.

## What Changes

- Английский текст по умолчанию для каждого ключа, рядом с русским в коде.
- Язык абонента берётся из Telegram: русский для ru, uk, be, kk, английский для остальных. Абонент меняет язык кнопкой.
- Тест: у каждого ключа есть английский текст с теми же подстановками.
- Кабинет получает тексты на языке абонента тем же механизмом.

**Не входит:** другие языки (их добавляет админ правкой текстов в админке), перевод админки.

## Capabilities

### New Capabilities
- `i18n`: языки текстов по умолчанию и выбор языка абонента.

### Modified Capabilities

Нет.

## Impact

- `texts`: поле английского текста в `Def`, файлы `default_*.go`.
- `bot`: выбор языка при регистрации.
