# Spec Delta

## Purpose

Бот и кабинет говорят с абонентом на его языке: русском или английском из коробки, другими языками после правки админом.

## ADDED Requirements

### Requirement: Английский для каждого текста
Каждый ключ текстов SHALL иметь английский текст по умолчанию с теми же подстановками, что и русский.

#### Scenario: Новый ключ без перевода
- **WHEN** разработчик добавил ключ без английского текста
- **THEN** тест текстов падает с именем ключа

### Requirement: Язык из Telegram
Новый абонент SHALL получать русский, если код языка Telegram `ru`, `uk`, `be` или `kk`, и английский для остальных кодов.

#### Scenario: Абонент из Германии
- **WHEN** незнакомый абонент с языком `de` прислал `/start`
- **THEN** меню на английском

#### Scenario: Абонент из Казахстана
- **WHEN** незнакомый абонент с языком `kk` прислал `/start`
- **THEN** меню на русском

### Requirement: Правка админа главнее умолчания
Текст, изменённый админом для языка, SHALL показываться вместо умолчания этого языка.

#### Scenario: Админ поправил английское приветствие
- **WHEN** админ изменил `bot.menu` для `en`
- **THEN** англоязычные абоненты видят новый текст, русскоязычные прежний
