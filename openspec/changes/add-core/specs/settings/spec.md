# Spec Delta

## Purpose

Настройки управляют поведением бота без правки кода и без перезапуска. У каждой настройки одно место хранения, поэтому правка в админке всегда работает.

## ADDED Requirements

### Requirement: В окружении только секреты и адреса
Из переменных окружения (`.env`) система SHALL читать только: токен бота, Telegram ID владельца, публичный адрес, адрес и токен панели, ключ шифрования, путь к базе. Остальные настройки из окружения не читаются.

#### Scenario: Лишняя переменная
- **WHEN** в `.env` указана переменная тарифа или текста
- **THEN** она игнорируется, при старте в журнал пишется предупреждение с её именем

#### Scenario: Нет обязательной переменной
- **WHEN** не задан токен бота
- **THEN** процесс не стартует и пишет, какой переменной не хватает

### Requirement: Реестр настроек
Каждая настройка SHALL быть описана в реестре: ключ, тип, значение по умолчанию, описание, группа. Настройки вне реестра не существуют.

#### Scenario: Неизвестный ключ
- **WHEN** запрос меняет настройку, которой нет в реестре
- **THEN** отказ с ошибкой

#### Scenario: Неверный тип
- **WHEN** в числовую настройку пишут текст
- **THEN** отказ с ошибкой проверки, старое значение остаётся

### Requirement: В базе только отличия
База SHALL хранить только значения, отличные от умолчания. Сброс настройки возвращает умолчание из реестра.

#### Scenario: Сброс
- **WHEN** админ сбрасывает настройку
- **THEN** её строка удалена из базы, действует значение по умолчанию

### Requirement: Правка без перезапуска
Изменённая настройка SHALL начать действовать не позже чем через 5 секунд без перезапуска процесса.

#### Scenario: Выключили пробный период
- **WHEN** админ выключает пробный период
- **THEN** через 5 секунд пробный период недоступен

### Requirement: Секреты зашифрованы
Секретные настройки (ключи касс) SHALL храниться в базе зашифрованными ключом из окружения и не отдаваться наружу целиком.

#### Scenario: Чтение ключа кассы
- **WHEN** админка запрашивает ключ кассы
- **THEN** она получает только признак «задан» и последние 4 символа
