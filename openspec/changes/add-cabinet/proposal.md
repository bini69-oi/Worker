# Proposal

## Why

Текстовый бот продаёт, но управлять подпиской в чате неудобно: устройства, история, подключение на новом телефоне.
Абоненту нужен кабинет: в Telegram он открывается как Mini App, в браузере как сайт. Это одна страница и один код.

## What Changes

- HTTP API кабинета `/api/app/*`: данные абонента и те же сценарии ядра, что зовёт бот.
- Вход в Telegram без пароля по подписанным данным Telegram (`initData`).
- Вход в браузере через бота: сайт показывает код, бот предлагает три кода, абонент нажимает свой.
- Сессии абонента: список не нужен, есть «Выйти» и «Выйти на всех устройствах».
- Фронт на Svelte, вшитый в бинарник: главная, подключение с QR, покупка, пополнение, история, устройства, рефералка, промокод.
- Stars внутри Telegram (`openInvoice`), остальные кассы ссылкой с опросом статуса.
- Светлая и тёмная тема, цвета Telegram внутри Telegram. Лёгкая страница: системные шрифты, без тяжёлых картинок.
- Типы ответов API пишутся в Go, файл типов TypeScript генерируется (`make types`).
- Сборка фронта и проверки фронта в CI: типы, тесты, размер, `npm audit`.

**Не входит:** веб-админка (следующая часть, но на том же сервере и той же сборке), вход по почте и через соцсети,
гостевая покупка без Telegram, темы на выбор, баннеры и свои блоки, рассылки, смена тарифа, докупка трафика.

## Capabilities

### New Capabilities
- `cabinet-auth`: вход в Telegram и в браузере, сессии абонента.
- `cabinet-api`: HTTP API кабинета, ошибки, лимиты.
- `cabinet-screens`: экраны кабинета и поведение внутри Telegram.
- `cabinet-build`: сборка фронта в бинарник, генерация типов, заголовки безопасности, бюджет размера.

### Modified Capabilities

Нет. Новые функции ядра (сессии абонента, вход через бота) описаны в `cabinet-auth`, миграция `003_cabinet.sql` только добавляет.

## Impact

- Новый код: `api/`, `web/` (Svelte), `cmd/gen-types`, обработка диплинка `web_` в `bot/`, функции ядра для входа абонента.
- Зависимости фронта: svelte, vite, typescript, svelte-check, vitest, qrcode-generator. Для Go новых нет.
- Для сборки фронта нужен Node.js, для запуска бинарника не нужен.
