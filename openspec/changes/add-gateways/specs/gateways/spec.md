# Spec Delta

## Purpose

Общие требования ко всем кассам: что касса обязана делать, чтобы деньги зачислялись ровно один раз и подделка не проходила.

## ADDED Requirements

### Requirement: Касса проходит общий набор тестов
Каждая касса SHALL проходить `pay/gatewaytest`: без ключей не видна, счёт создаётся, поддельный вебхук отклоняется, повтор не зачисляет дважды, неверная сумма не зачисляется.

#### Scenario: Новая касса
- **WHEN** в `pay/` добавлена касса
- **THEN** её тест зовёт `gatewaytest.Run` и проходит

### Requirement: Вебхук без подписи проверяется у кассы
Если касса не подписывает вебхук, касса SHALL переспросить статус платежа у API кассы и вернуть событие только по ответу API.

#### Scenario: Поддельный вебхук без подписи
- **WHEN** на `/pay/<касса>` пришёл вебхук «оплачено», а API кассы говорит «не оплачен»
- **THEN** деньги не зачислены

### Requirement: Касса выключена по умолчанию
Новая касса SHALL быть выключенной, пока админ не включил её и не заполнил ключи.

#### Scenario: Обновление бота
- **WHEN** владелец обновил бота с новыми кассами
- **THEN** абоненты видят только те кассы, что были у них раньше

### Requirement: Ключи не утекают
Ключи кассы SHALL храниться секретными настройками и не попадать в текст ошибки и журнал.

#### Scenario: Касса ответила ошибкой
- **WHEN** API кассы вернул 401
- **THEN** в тексте ошибки нет ключа кассы
