# Proposal

## Why

Ядро умеет продавать, но абоненту до него не дотянуться. Нужен текстовый Telegram-бот: абонент от `/start` до работающего VPN
проходит в чате, без сайта. Бот это тонкий экран: он показывает данные и зовёт функции ядра.
Админам нужны уведомления в группу с кнопками, чтобы реагировать, не открывая админку.

## What Changes

- Свой маленький клиент Telegram Bot API на стандартной библиотеке: только нужные методы.
- Приём обновлений вебхуком с секретом. Для разработки на своём компьютере режим опроса.
- Экраны абонента одним сообщением, которое правится: главное меню, подписка, подключение, покупка, баланс, пробный период,
  рефералка, промокод, устройства, поддержка.
- Подключение: одно-два приложения, кнопка открывает приложение сразу со ссылкой подписки.
- Оплата: счета Stars (разовые и автоподписка) и ссылки остальных касс. Сообщение абоненту на каждый исход оплаты.
- Диплинки `ref_`, `promo_`, `paid_`.
- Подписка на канал перед пробным периодом, если админ её включил.
- Поддержка: сообщение абонента уходит в тему «Поддержка», админ отвечает реплаем.
- Уведомления админам в группу-форум по темам видов событий, с кнопками «Бан», «+7 дней», «Открыть в админке».
  Подтверждения входа и опасных действий владельцу в личку.
- Уведомления абоненту из очереди ядра: напоминания, продление, пополнение, конец подписки.
- Техработы: абонент видит текст, админы работают.
- Ядро получает недостающее: расчёт цены с недостачей, бан, выдачу дней, проверку канала, события о новых абонентах
  и пробных периодах, сообщения о конце подписки и истёкшем платеже, режим техработ.

**Не входит:** кабинет и Mini App, веб-админка, рассылки, конструктор меню, смена тарифа, докупка трафика и устройств,
скидки «вернись», ИИ-поддержка, установщик. Всё это в [features.md](../../../docs/features.md) с частью, где появится.

## Capabilities

### New Capabilities
- `telegram-api`: клиент Bot API, вебхук и опрос, лимиты Telegram.
- `bot-screens`: экраны, кнопки, команды, диплинки, ввод, флуд, бан, техработы.
- `bot-connect`: экран подключения и переход в приложение.
- `bot-payments`: пополнение, Stars, ссылки касс, исходы оплаты.
- `support-chat`: поддержка через тему «Поддержка».
- `admin-notify`: подтверждения в личку, события в темы, кнопки действий.
- `user-notify`: уведомления абоненту из очереди ядра.

### Modified Capabilities

Нет. Новые функции ядра описаны в спеках этой части, миграция `002_bot.sql` только добавляет.

## Impact

- Новый код: `tg/`, `bot/`, сборка в `cmd/worker`, новые функции в `core/`.
- Зависимостей не добавляется.
- Внешние системы: Telegram Bot API.
