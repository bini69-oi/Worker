# Spec Delta

## Purpose

Как абонент от ссылки подписки доходит до работающего VPN. Экран короткий: одно-два приложения и кнопка, которая открывает приложение сразу со ссылкой.

## ADDED Requirements

### Requirement: Экран подключения короткий
Экран подключения SHALL показывать только приложения из настройки `connect.apps` в её порядке, по умолчанию два. Для каждого кнопки «Скачать» под платформы и «Добавить подписку». Внизу «Скопировать ссылку».

#### Scenario: Умолчания
- **WHEN** админ не трогал настройку `connect.apps`
- **THEN** на экране два приложения

#### Scenario: Неизвестное приложение в настройке
- **WHEN** в `connect.apps` записан id, которого нет в таблице приложений
- **THEN** настройка не сохраняется, админ видит ошибку с допустимыми id

### Requirement: Сырая схема не показывается
Бот SHALL не показывать ссылки вида `happ://` текстом. Переход в приложение идёт только кнопкой.

#### Scenario: Экран без схем
- **WHEN** абонент открыл экран подключения
- **THEN** в тексте экрана нет строк со своей схемой приложения

### Requirement: Переход в приложение через `/dl`
Кнопка «Добавить подписку» SHALL вести на `PUBLIC_URL/dl/<app>/<токен>`. Сервер проверяет подпись и срок токена, находит ссылку подписки абонента и отвечает переходом 302 на схему приложения.

#### Scenario: Живой токен
- **WHEN** абонент нажал «Добавить подписку» для приложения с шаблоном `happ://add/{url}`
- **THEN** браузер получил 302 на `happ://add/<ссылка подписки>`

#### Scenario: Токен старше суток
- **WHEN** открыт адрес с токеном, выданным 25 часов назад
- **THEN** ответ «Ссылка устарела, откройте экран подключения в боте заново», перехода нет

#### Scenario: Подделанный токен
- **WHEN** в токене изменён id абонента
- **THEN** подпись не сходится, ответ 404

### Requirement: Ссылка подписки не в адресе
Адрес `/dl` SHALL не содержать ссылку подписки и id абонента открытым текстом.

#### Scenario: Адрес кнопки
- **WHEN** тест читает адрес кнопки «Добавить подписку»
- **THEN** в нём нет ссылки подписки и нет id абонента открытым текстом

### Requirement: После перевыпуска старые переходы не работают
Переход `/dl` SHALL сверять отпечаток ссылки подписки в токене с текущей ссылкой. Ссылку перевыпустили: старая кнопка отвечает «Ссылка устарела». Так утёкшая кнопка не выдаёт новую ссылку.

#### Scenario: Перевыпустил ссылку из-за утечки
- **WHEN** абонент перевыпустил ссылку, а кто-то открыл старую кнопку «Добавить подписку» в пределах суток
- **THEN** ответ «Ссылка устарела», новой ссылки в ответе нет

### Requirement: Переход ограничен по частоте
Адрес `/dl` SHALL принимать не больше 120 запросов в минуту с одного IP.

#### Scenario: Перебор токенов
- **WHEN** с одного IP пришло 200 запросов `/dl` за минуту
- **THEN** лишние получили 429
