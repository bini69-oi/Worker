# Spec Delta

## Purpose

Что продаём: тарифы со сроками и ценами и промокоды. Функции ядра уже есть (`SaveTariff`, `AllTariffs`, `SavePromo`), админка даёт к ним экраны.

## ADDED Requirements

### Requirement: Тарифы
Админ с правом `tariffs` SHALL видеть все тарифы, включая скрытые, создавать и править тариф: название, трафик, устройства, сброс трафика, сквады, сроки с ценами, порядок, показывать ли.

#### Scenario: Новая цена
- **WHEN** админ поменял цену срока 30 дней с 200 на 250 ₽
- **THEN** новые покупки по 250 ₽, уже купленные подписки продлеваются по цене из правил ядра

#### Scenario: Скрыл тариф
- **WHEN** админ скрыл тариф
- **THEN** новые абоненты его не видят, у кого он есть, могут продлить

### Requirement: Сквады из панели
Поле сквадов SHALL предлагать выбор из сквадов, которые вернула панель. Ввод руками не нужен.

#### Scenario: Выбор сквада
- **WHEN** админ открыл тариф
- **THEN** он видит список сквадов панели с галочками

### Requirement: Промокоды
Админ с правом `promo` SHALL видеть промокоды с числом активаций, создавать и выключать их. Код от 6 до 32 символов.

#### Scenario: Новый промокод
- **WHEN** админ создал код `SPRING26` на 7 дней с лимитом 100
- **THEN** код работает в боте и кабинете, счётчик активаций растёт

#### Scenario: Короткий код
- **WHEN** админ ввёл код `ABC`
- **THEN** ответ с кодом ошибки, код не создан

### Requirement: Ссылка на промокод
Карточка промокода SHALL показывать готовую ссылку `t.me/<бот>?start=promo_<код>` с кнопкой «Скопировать».

#### Scenario: Скопировать ссылку
- **WHEN** админ нажал «Скопировать» у промокода
- **THEN** ссылка с кодом в буфере обмена
