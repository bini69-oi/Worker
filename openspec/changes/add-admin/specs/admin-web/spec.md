# Spec Delta

## Purpose

Сайт админки: вход, сессии, защита запросов и проверка прав на каждый адрес. Логика входа уже в ядре, сайт её только показывает.

## ADDED Requirements

### Requirement: Вход паролем и кодом
`POST /api/admin/login` SHALL принимать Telegram ID и пароль и отдавать код для экрана. Сессия выдаётся, только когда админ выбрал этот код в Telegram.

#### Scenario: Успешный вход
- **WHEN** админ ввёл верный пароль и выбрал в Telegram код с экрана
- **THEN** опрос `GET /api/admin/login/{id}` поставил cookie сессии, страница открыла сводку

#### Scenario: Неверный пароль
- **WHEN** пароль неверный
- **THEN** ответ с кодом ошибки, в Telegram ничего не пришло, ошибка засчитана в защиту от перебора

### Requirement: Cookie админки отдельно
Cookie сессии админки SHALL быть `HttpOnly`, `Secure`, `SameSite=Strict` с путём `/api/admin` и не совпадать с cookie кабинета.

#### Scenario: Сессия кабинета
- **WHEN** запрос в `/api/admin/*` пришёл с cookie кабинета
- **THEN** ответ 401

### Requirement: Защита от подделки запроса
Изменяющий запрос в `/api/admin/*` SHALL требовать `X-Worker: 1` и `Content-Type: application/json`.

#### Scenario: Форма с чужого сайта
- **WHEN** чужой сайт отправил форму на изменение баланса с cookie админа
- **THEN** ответ 403, баланс не изменился

### Requirement: Права на каждый адрес
Каждый адрес `/api/admin/*` SHALL проверяться ядром по праву из таблицы прав в `design.md`. Сайт прячет недоступные разделы, но не заменяет проверку.

#### Scenario: Помощник без права зовёт адрес напрямую
- **WHEN** помощник без права `tariffs` прислал `POST /api/admin/tariffs`
- **THEN** ответ 403, в журнале запись об отказе, владелец получил тревогу

#### Scenario: Меню помощника
- **WHEN** помощник с правами `users` и `support` открыл админку
- **THEN** он видит только Абонентов

### Requirement: Админка не встраивается
Ответы `/admin/` SHALL нести `Content-Security-Policy` с `frame-ancestors 'none'` и скриптами только со своего адреса.

#### Scenario: Встроили во фрейм
- **WHEN** чужой сайт встроил `/admin/` во фрейм
- **THEN** браузер не показал страницу

### Requirement: Выход
`POST /api/admin/logout` SHALL закрывать текущую сессию. Отключение помощника закрывает все его сессии.

#### Scenario: Помощника убрали
- **WHEN** владелец убрал помощника
- **THEN** следующий запрос помощника получает 401

### Requirement: Работает на телефоне
Каждый раздел админки SHALL помещаться в экран шириной 360 пикселей без горизонтальной прокрутки. Таблицы на узком экране становятся карточками.

#### Scenario: Карточка абонента с телефона
- **WHEN** админ открыл карточку абонента на телефоне
- **THEN** все данные и кнопки видны без горизонтальной прокрутки
