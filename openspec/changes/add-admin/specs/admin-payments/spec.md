# Spec Delta

## Purpose

Где админ видит деньги: все платежи всех касс, ручные переводы на подтверждение, возвраты Stars.

## ADDED Requirements

### Requirement: Список платежей
`Payments` SHALL отдавать платежи страницами по 50 с фильтром по статусу, кассе и датам. В строке: абонент, касса, сумма, статус, создан, оплачен.

#### Scenario: Ждущие ручные
- **WHEN** админ выбрал кассу «ручное зачисление» и статус «ожидает»
- **THEN** он видит только такие платежи, новые сверху

### Requirement: Ручное подтверждение
Админ с правом `grant` SHALL подтверждать ручной платёж кнопкой. Подтверждение зачисляет деньги ровно один раз.

#### Scenario: Двойной клик «Подтвердить»
- **WHEN** админ дважды быстро нажал «Подтвердить»
- **THEN** деньги зачислены один раз, второе нажатие получило «уже зачислен»

### Requirement: Возврат Stars
Владелец SHALL возвращать оплаченный платёж Stars кнопкой. Ядро зовёт Telegram и отменяет зачисление.

#### Scenario: Возврат
- **WHEN** владелец вернул платёж Stars
- **THEN** звёзды вернулись абоненту, баланс уменьшен, в журнале запись

#### Scenario: Помощник пытается вернуть
- **WHEN** помощник прислал запрос возврата
- **THEN** ответ 403

### Requirement: Платёж ведёт к абоненту
Строка платежа SHALL открывать карточку абонента.

#### Scenario: Переход
- **WHEN** админ нажал на абонента в строке платежа
- **THEN** открылась его карточка
