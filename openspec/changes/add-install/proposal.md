# Proposal

## Why

Сейчас Worker собирается из исходников руками. Владельцу нужна установка одной командой на чистый сервер,
безопасное обновление и бэкапы, которые можно восстановить.

## What Changes

- `install.sh`: одна команда на Debian или Ubuntu. Скачивает релиз, проверяет подпись, спрашивает токен бота, Telegram ID,
  домен и панель, создаёт ключ шифрования, ставит службу systemd в песочнице и Caddy с https.
- `worker update`: скачивает новый релиз, проверяет подпись, делает бэкап, меняет бинарник, проверяет, что бот поднялся,
  иначе откатывает.
- `worker backup` и `worker restore`: зашифрованный бэкап базы, проверка целостности, хранение последних N, ежедневно сам.
- Релизы: сборка под amd64 и arm64, контрольные суммы, подпись ключом проекта, публикация в GitHub по тегу.

**Не входит:** Docker-образ, обновление из админки или бота, установка на другие системы, кроме Debian и Ubuntu.

## Capabilities

### New Capabilities
- `install`: установка одной командой и служба.
- `backup`: бэкап и восстановление.
- `release`: сборка, подпись и обновление.

### Modified Capabilities

Нет.

## Impact

- Новое: `install/install.sh`, `install/worker.service`, `install/Caddyfile.tmpl`, `cmd/worker/update.go`, `cmd/worker/backup.go`,
  `.github/workflows/release.yml`, `cmd/sign` (подпись релиза в CI).
- Зависимостей Go не добавляется: подпись Ed25519 из стандартной библиотеки.
