# Spec Delta

## Purpose

Установка Worker на чистый сервер одной командой и работа службы в песочнице.

## ADDED Requirements

### Requirement: Подпись проверяется до установки
Установщик SHALL проверять подпись `SHA256SUMS` вшитым открытым ключом и сумму бинарника до того, как что-то ставит.

#### Scenario: Подменённый бинарник
- **WHEN** сумма скачанного бинарника не совпала с подписанным списком
- **THEN** установка остановлена, на сервере ничего не изменилось

### Requirement: Ответы проверяются сразу
Установщик SHALL проверять токен бота запросом `getMe`, панель запросом версии и домен A-записью до записи настроек.

#### Scenario: Опечатка в токене
- **WHEN** владелец ввёл неверный токен
- **THEN** установщик говорит, что токен не принят, и спрашивает снова

### Requirement: Служба без прав
Служба SHALL работать от пользователя `worker` без root, писать только в `/var/lib/worker` и слушать только `127.0.0.1`.

#### Scenario: Оценка песочницы
- **WHEN** выполнено `systemd-analyze security worker`
- **THEN** оценка не выше 2.0

### Requirement: Занятые порты
Если 80 или 443 заняты, установщик SHALL не ставить Caddy и напечатать готовый кусок конфига nginx для домена.

#### Scenario: На сервере стоит панель
- **WHEN** порт 443 занят nginx
- **THEN** Caddy не установлен, на экране конфиг nginx с проксированием на `127.0.0.1:8080`
