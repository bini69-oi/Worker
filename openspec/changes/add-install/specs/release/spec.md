# Spec Delta

## Purpose

Релизы, подлинность которых проверяется, и обновление, которое не ломает рабочий бот.

## ADDED Requirements

### Requirement: Релиз подписан
CI SHALL на тег собирать бинарники amd64 и arm64, считать `SHA256SUMS` и подписывать его ключом Ed25519 из секрета.

#### Scenario: Тег v1.0.0
- **WHEN** запушен тег `v1.0.0`
- **THEN** в релизе два бинарника, `SHA256SUMS` и `SHA256SUMS.sig`

### Requirement: Обновление проверяет подпись
`worker update` SHALL проверять подпись встроенным открытым ключом и не ставить релиз с неверной подписью.

#### Scenario: Подпись не сошлась
- **WHEN** подпись `SHA256SUMS` неверна
- **THEN** обновление отказывает, работает прежний бинарник

### Requirement: Откат при неудаче
Если после обновления служба не ответила на `/healthz` за 60 секунд, `worker update` SHALL вернуть прежний бинарник и перезапустить службу.

#### Scenario: Новая версия не стартует
- **WHEN** новая версия падает при старте
- **THEN** через минуту работает прежняя версия, владелец видит причину в выводе команды
