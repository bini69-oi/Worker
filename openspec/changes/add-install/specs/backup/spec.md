# Spec Delta

## Purpose

Бэкапы базы, которые нельзя прочитать без ключа и можно проверить и восстановить.

## ADDED Requirements

### Requirement: Бэкап зашифрован
Файл бэкапа SHALL быть зашифрован AES-256-GCM ключом, выведенным из `SECRET_KEY`. Без ключа его не открыть.

#### Scenario: Чужой скачал бэкап
- **WHEN** файл бэкапа открыт без ключа
- **THEN** в нём нет ни одной строки базы открытым текстом

### Requirement: Ежедневно и с пределом
Фоновая задача SHALL делать бэкап раз в сутки и хранить `backup.keep` последних.

#### Scenario: Пятнадцатый день
- **WHEN** `backup.keep = 14` и сделан пятнадцатый бэкап
- **THEN** самый старый удалён, осталось 14

### Requirement: Восстановление с проверкой
`worker restore` SHALL работать только при остановленной службе, проверять целостность расшифрованной базы и сохранять текущую базу перед подменой.

#### Scenario: Испорченный файл
- **WHEN** файл бэкапа испорчен
- **THEN** восстановление отказывает, текущая база не тронута
