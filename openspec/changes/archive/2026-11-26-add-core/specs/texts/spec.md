# Spec Delta

## Purpose

Все слова, которые видит абонент, хранятся как тексты по ключам. Админ меняет любой текст без кода, а бот, Mini App и уведомления берут тексты из одного места.

## ADDED Requirements

### Requirement: Текст по ключу
Каждая строка для абонента SHALL иметь ключ (например `buy.success`) и текст по умолчанию в коде. Строк для абонента вне ключей нет.

#### Scenario: Текст по умолчанию
- **WHEN** админ не менял текст `buy.success`
- **THEN** абонент видит текст по умолчанию

#### Scenario: Текст изменён
- **WHEN** админ поменял текст `buy.success`
- **THEN** абонент видит новый текст не позже чем через 5 секунд

### Requirement: Плейсхолдеры
Текст SHALL поддерживать подстановки в фигурных скобках, например `{days}` и `{balance}`. Для каждого ключа известен список допустимых подстановок.

#### Scenario: Подстановка
- **WHEN** текст «Осталось {days} дн.» и до окончания 5 дней
- **THEN** абонент видит «Осталось 5 дн.»

#### Scenario: Неизвестная подстановка
- **WHEN** админ сохраняет текст с `{foo}`, которой нет у ключа
- **THEN** сохранение отклонено с подсказкой, какие подстановки есть

### Requirement: Языки
Тексты SHALL храниться по языкам. Язык абонента берётся из Telegram. Если перевода нет, показывается язык по умолчанию из настроек.

#### Scenario: Нет перевода
- **WHEN** у абонента английский, а английского текста ключа нет
- **THEN** абонент видит русский текст

### Requirement: Сброс к умолчанию
Админ SHALL сбросить текст к умолчанию.

#### Scenario: Сброс
- **WHEN** админ сбрасывает изменённый текст
- **THEN** абонент видит текст по умолчанию
