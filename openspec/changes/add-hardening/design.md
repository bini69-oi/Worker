# Design

## Decisions

### Модель угроз

| Кто | Чего хочет | Чем закрыто |
|---|---|---|
| Абонент | бесплатная подписка, чужие деньги | логика только в ядре, проверка владельца объекта, деньги одной транзакцией, повтор не зачисляет |
| Посторонний в интернете | поддельная оплата, вход в админку | подписи касс и сверка с API, пароль плюс код в Telegram, пределы попыток |
| Помощник админа | больше своих прав | права в ядре на каждое действие, журнал, тревоги владельцу, опасное только через «Да» владельца |
| Укравший сессию или пароль | деньги и реквизиты | второй фактор в Telegram, денежные настройки через «Да», сессии видны и закрываются |
| Укравший копию базы | токены и ключи | секреты зашифрованы, токены сессий хэшами, бэкапы зашифрованы |
| Взломавший сервер | всё | песочница systemd, тревоги владельцу, быстрая смена ключей; полностью не закрывается, это сказано прямо |

Документ обновляется в каждой части, где появляется новый вход снаружи.

### Защита HTTP в одном месте
`guard.Secure(handler)` ставит на все ответы `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options: DENY`
(кроме `/app/`, где свой CSP), `Cache-Control: no-store` для API. Сервер без заголовка `Server`.
**Почему в одном месте:** новый адрес не забудет заголовки.

### Fuzz
У каждого разбора чужого ввода есть `FuzzXxx`. CI запускает `go test -fuzz` по 30 секунд на каждый fuzz-тест в main.
Найденный вход сохраняется в `testdata/fuzz` и становится обычным тестом.

### Живой прогон атак
`scripts/attack/` это набор коротких проверок на Go, который бьёт по тестовому серверу:
подделка вебхука каждой включённой кассы, перебор пароля админки, `initData` с чужой подписью, форма с чужого сайта на админку,
перебор промокодов, 100 нажатий в секунду в бота. Ожидание каждой проверки записано, итог: всё отбито или список того, что прошло.
Запускается перед каждым выпуском, результат в `docs/release-check.md`.

### Список адресов админки
`admin.allow_ips`: пусто значит все, иначе адреса и подсети через запятую. Проверка по настоящему IP (`guard.RealIP`).
Меняется только через «Да» владельца, чтобы угнанная сессия не открыла админку всему интернету.

## Risks / Trade-offs

- [Fuzz в CI удлиняет проверку] → только в main и по 30 секунд, на ветках обычные тесты.
- [Владелец закрыл админку своим IP и сменил провайдера] → сброс списка командой на сервере `worker admin allow-all`.
